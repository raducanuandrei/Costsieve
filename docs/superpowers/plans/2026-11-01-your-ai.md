Retain the free local core and existing visual direction. Work in the existing clean feat/document-analysis worktree (base 5cf0687); no deployment or account-permission changes.

Builder choices: a provider-neutral skill and optional reviewed report transfer, not a simulated ChatGPT sign-in. No provider token, new model dependency, automatic cloud upload, global skill installation or new source connector. The AI uses read-only capabilities available in its host. ## 3. Reviewed report

- packages/engine/src/ai-handoff.ts exports createAiHandoff(analysis,{currency,includeLabels?,scenario?}) and renderAiHandoff(handoff). Whitelist exact financial totals, selected currency, UTC period, origin, coverage counts, top ten vendor/category groups, up to ten review candidates with bounded source previews and an optional same-currency applied scenario. Alias vendor/category names by default, omit source IDs/filenames/raw text/transaction IDs, and show all truncation counts. Hiding names is not anonymity; numbers and dates remain sensitive. Unsupported currencies/scenario mismatches rejected; missing revenue means null result.
- Tests first: deliberate private marker does not escape through recommendation explanations/IDs/caveats; labels are opt-in; partial coverage and negative net benefits preserved; large inputs bounded; unknown savings remain unknown.
